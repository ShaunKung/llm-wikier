## 功能说明

`wiki-query` 用于基于 wiki 内容回答用户问题。它会先从索引找到相关页面，阅读内容后综合回答。重要的答案可以沉淀为新的 wiki 页面。

## 执行流程

1. **分析问题**：理解用户问题的核心主题和关键词
2. **查找相关页面**：从 `.wiki/index.md` 定位相关页面
3. **阅读页面内容**：读取相关实体、概念、源文件摘要
4. **追踪链接**：如需要，沿链接阅读更多相关页面
5. **综合回答**：基于阅读内容回答问题
6. **沉淀答案**：（可选）将答案保存为分析页面

## 使用方法

### 直接提问

```
/wiki-query 这篇文章的核心观点是什么？
```

### 指定主题

```
/wiki-query 关于"机器学习"这个概念有哪些相关内容？
```

### 比较类问题

```
/wiki-query 对比文章A和文章B的观点差异
```

### 追踪类问题

```
/wiki-query 从这个概念出发，有哪些相关的实体和其他概念？
```

## 回答策略

### 1. 信息检索

- 先阅读 `.wiki/index.md` 找到相关分类
- 根据问题关键词匹配实体、概念页面
- 阅读源文件摘要获取详细引用

### 2. 信息综合

- 整合多个页面中的相关信息
- 标注信息的来源页面
- 对矛盾信息说明不同观点

### 3. 回答格式

```markdown
## 问题主题

### 核心回答
[综合回答内容]

### 相关实体
- [[实体A]]: [在这一主题中的角色]
- [[实体B]]: [在这一主题中的角色]

### 相关概念
- [[概念A]]: [与问题的关系]
- [[概念B]]: [与问题的关系]

### 来源参考
- [[源文件1-summary|源文件1]]: [相关部分]
- [[源文件2-summary|源文件2]]: [相关部分]

---
*基于 wiki 内容生成*
```

## 答案沉淀

当回答具有长期价值时，建议沉淀为新页面：

### 触发条件

- 综合分析类问题
- 比较类问题
- 需要多个源文件支撑的问题
- 用户明确要求保存

### 沉淀流程

1. 将回答保存为 `.wiki/analysis/主题.md`
2. 在页面中标注生成时间和触发问题
3. 更新 `.wiki/index.md` 的分析页面列表
4. 在 `.wiki/log.md` 记录操作

### 沉淀页面格式

```markdown
# 分析主题

## 原始问题
[用户提出的问题]

## 分析结论
[详细分析内容]

### 要点总结
- 要点1
- 要点2
- 要点3

## 相关实体
- [[实体A]]
- [[实体B]]

## 相关概念
- [[概念A]]
- [[概念B]]

## 参考资料
- [[源文件1-summary|源文件1]]
- [[源文件2-summary|源文件2]]

---
*生成时间: YYYY-MM-DD*
*基于 wiki 内容自动生成*
```

## 与普通问答的区别

| 特性 | 普通问答 | /wiki-query |
|------|---------|-------------|
| 信息源 | 模型知识 | wiki 内容 |
| 可追溯性 | 无 | 有，标注来源 |
| 可沉淀性 | 无 | 可保存为页面 |
| 一致性 | 可能不一致 | 基于同一知识库 |

## 常见问题类型

### 事实类

```
/wiki-query 文章A的作者主张什么？
```

策略：定位源文件摘要和相关实体页面

### 概念类

```
/wiki-query "概念X"在本知识库中如何定义？
```

策略：阅读概念页面，追踪相关源文件

### 关系类

```
/wiki-query 实体A和实体B有什么关系？
```

策略：分别阅读两个实体页面，检查共同引用

### 演变类

```
/wiki-query 概念X在不同文章中的定义有何变化？
```

策略：阅读概念页面，检查争议/不同观点章节

### 空白类

```
/wiki-query 知识库中关于"主题Y"有哪些内容？
```

策略：从索引出发，汇总所有相关页面

## 输出示例

### 正常回答

```
根据 wiki 内容回答您的问题：

## 关于"机器学习"的相关内容

### 核心概念
在本知识库中，"机器学习"定义为...

### 相关实体
- [[吴恩达]]: 在源文件"深度学习笔记"中被提及
- [[OpenAI]]: 在源文件"AI发展报告"中被讨论

### 相关概念
- [[深度学习]]: 机器学习的子领域
- [[神经网络]]: 机器学习的核心技术

### 来源参考
- [[深度学习笔记-summary|深度学习笔记]]
- [[AI发展报告-summary|AI发展报告]]

是否将此回答保存为分析页面？
```

### 信息不足

```
根据 wiki 检索，未找到直接关于"主题X"的内容。

相关度最高的页面：
- [[概念Y]]: 可能相关
- [[实体Z]]: 提及类似概念

建议：
1. 运行 /wiki-ingest 添加相关源文件
2. 扩展搜索关键词
3. 查看相关页面追踪更多线索
```

## 与其他命令的关系

- 处理后如果有新发现，可以运行 `/wiki-ingest` 添加新源
- 如果发现 wiki 不一致，可以运行 `/wiki-lint` 检查
- 如果关键页面缺失，可以提示运行 `/wiki-update`
